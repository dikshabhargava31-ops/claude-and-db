# Day 001 – Enquiry handling: re-edit storylines

Source: `raw/day001.mp4` (1080×1920, 120.8 s, 12 illustrated shots of 4–17 s, text cards burned into the top ~700 px).
Audience: coaching-centre owners and teachers. The one thing to remember: **ask 3 questions on the first call, sort each enquiry Hot / Warm / Cold, follow up each one differently.**

All copy is from the original cards, verbatim (Hinglish). Every storyline crops the illustrations below the old cards and rebuilds the text as large animated type, so nothing gets stacked on top of the old cards.

## A. "15 → 3" (recommended: the number is the hook, and the sorter makes the system visible)
- Device / form: a number lands, then one object (the enquiry card) is sorted and followed: an object-to-object chain, cut every 2–3 s.
- First 2 s: the empty-classroom shot punched in, with a giant amber "15 enquiry" dropping in. It is slashed to "3 admission?" on the beat.
- Beats: hook 15→3 → "Fees se pehle, 3 sawaal" (three numbered chips stamp in, one per cut) → the sorter: chips fly into HOT / WARM / COLD lanes → HOT: "Centre bulao → Trial ki date" → WARM: "Pressure nahi, value do" → COLD: "Peeche mat bhaago" → TRACK list (H/W/C/ADM) → claim "3 sawaal → Hot / Warm / Cold → alag follow-up" → "Follow for Day 002".
- Look: the brand's navy ground and amber accent, Inter Black at about 120 px, with Hot red, Warm amber and Cold cyan as the only extra colours.
- Sound: the original track (if it is music only) or a beat-led bed, with whooshes on the cuts and a stamp on each chip. Length 45–55 s.

## B. "Ek enquiry ka safar" (one parent, start to finish)
- Device / form: a worked example. One parent's call (Rohan, 9th) goes through every step, with each shot ending on the object that opens the next.
- First 2 s: the phone ringing on the desk, with the caption "Rohan ke papa ka call aaya. Ab?"
- Beats: call → 3 questions answered → tagged HOT → "Centre bulao" → trial date fixed → the contact list flips to ADM → "Har enquiry alag" → end card.
- Look: the same as A, but with a warmer, slower camera (push-ins instead of hard cuts).
- Sound: soft lo-fi bed, a phone ring and a tick on each step. Length 35–45 s.

## C. "Galti vs sahi" (the bold one: a myth turned over)
- Device / form: type carries the argument. Each common mistake is struck through, with the fix printed over it. Hard cuts on the beat, and the illustrations only flash for 1 s.
- First 2 s: the slogan "Phone pe fees bata di?" in big type, struck through with a red ✗.
- Beats: "Phone pe sab bata do" ✗ → "Centre bulao" ✓ / "Roz call karke pressure" ✗ → "Har 3–4 din value do" ✓ / "Cold ko bhool jao" ✗ → "Mahine mein 1 message" ✓ / "Number bas save" ✗ → "H / W / C / ADM tag" ✓ → claim → end card.
- Look: full-bleed colour fields (navy / red / amber) that switch on the beat.
- Sound: punchy percussion, with a buzzer on ✗ and a ding on ✓. Length 30–40 s.
