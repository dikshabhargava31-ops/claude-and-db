# Kallaway-style CUET reels: how to make one

This is the playbook for turning a long green-screen talking-head video into short reels in the Kallaway style. Reel 02 (Tip 6, "Cut-off depends on the course") is the approved reference: `videos/cuet-reel-02k/`. The other reels follow the same steps.

Each reel is generated by `videos/_tools/build_kallaway.py`. Its content lives in the `REELS` dictionary at the top of that file. The look, layout, grade and fixes from review live in the script. Content-only changes for one reel go in its `REELS` entry.

---

## 1. The style, in rules

| Element | Rule |
| --- | --- |
| Background | Near-black `#0E0E0E` with film grain, a vignette and a soft red light behind the presenter |
| Headlines | Inter Black, ALL CAPS, tight line spacing, white |
| Hero word | **One per frame**: red `#E3161B` *Instrument Serif Italic* with a red glow |
| Labels | Dark grey rounded pill with a thin border. Step pills ("TIP 6") get a red outline |
| Data | Neon green `#3DFF8A`, used **only** for numbers and bars |
| Graphic text | **Always English** (slides, overlays, hook, CTA). Only the captions follow the Hinglish speech |
| Captions | One lowercase word at a time, white, small, with a full stop at the end of each sentence |
| Layout | Switch every 2–4 s between **full face** and **split screen** (slide on the top 60%, face in a rounded card below) |
| Opening | **No title card.** Frame 0 is the presenter talking, with the hook text above his head |
| Ending | Hold the face through the pause after the last word, then fade in "COMMENT *MENTOR*" over it and hold for 3 s |
| Logo | Small signature at the bottom centre (currently the text "EVERYTHING CUET"; swap for the real logo) |
| Places | Draw the real thing when it's named (Hindu College got a line-drawn college facade) |

## 2. What you need

- The source video in `videos/<name>/raw/`. This folder is git-ignored, so footage never lands in the repository.
- Tools from `scripts/setup-video-tools.sh` (`ffmpeg`, `auto-editor`, `scenedetect`). `npx hyperframes` handles the rest.
- The word-level transcript: `videos/cuet-tips-src/words_rom.json` (romanised Hinglish) and `words_hi.json` (Whisper's original).

---

## 3. Step by step

### Step 1: Transcribe (once per source video)

Whisper large-v3 handles Hindi/Hinglish well, but it's slow on 4 CPUs (about an hour for 5 minutes of audio). Split long audio into halves and raise the timeout:

```bash
ffmpeg -i videos/<name>/raw/source.mp4 -ac 1 -ar 16000 full.wav
```

```bash
npx hyperframes transcribe full.wav --model large-v3 --language hi --json --timeout 10800000
```

Then romanise and fix the names Whisper mishears (it hears "CUET" as "CUT", for example):

```bash
python3 videos/cuet-tips-src/romanize.py words_hi.json videos/cuet-tips-src/words_rom.json
```

Read the transcript before using it. Add any new mishearings to the `FIX` table in `romanize.py`.

### Step 2: Pick the reel's segment

- One reel = **one complete thought** that makes sense on its own. Skip lines that point at other videos ("part 1 mein…", "subscribe karo").
- Find the exact cut points from the audio, not from Whisper's timings, because Whisper's word ends can be early:

```bash
ffmpeg -ss 50 -t 8 -i full.wav -af silencedetect=noise=-35dB:d=0.12 -f null - 2>&1 | grep silence_
```

- `segment` = `[first word start, end of the last word]`. **End the cut inside the silence after the last word.** Reel 02 originally clipped "farak" and felt abrupt.

### Step 3: Write the reel's entry in `REELS`

Copy the `"tip6-cutoff"` entry and change the content:

| Key | What it holds |
| --- | --- |
| `segment` | `[start, end]` in source seconds |
| `fix` | Caption corrections keyed by the word's source start time (`""` drops a word). Use it to drop a stray word that belongs to the next sentence |
| `stops` | Start times of words that end a sentence (they get a full stop) |
| `beats` | The layout plan: `{"t": source time, "mode": "full" or "split", "slide" or "overlay": id}`. Switch every 2–4 s, and put a switch on each new idea |
| `punches` | Zoom-ins on emphasis: `{"t", "until"}`. Skip one when an overlay sits above the head in that beat |
| `slides` | HTML for split-screen slides: `pill`, `h1`, `body`, a `serif hero` word, bars and so on |
| `overlays` | Text above the head in full-face beats. The first beat's overlay is the hook (`"static": True`, so it's readable at frame 0) |
| `slide_js` | Extra timed animation (bars growing, numbers counting, a line drawing on). Write `{T(source time)}` for timing |
| `cta` | `top` / `hero` / `line` for the end frame |

Copy rules for slides:
- English only, ALL CAPS headlines, at most about 18 characters per headline line (or it wraps).
- Exactly one `serif hero` word per slide.
- Reveal the key line (`class="... reveal"`) on the word where he says it.

### Step 4: Build

```bash
python3 videos/_tools/build_kallaway.py <reel key> videos/cuet-tips-src/words_rom.json <unused keyed.webm path> videos/<name>/raw/source.mp4 videos/<reel dir>
```

The build does all of the following automatically:
- **Re-keys the green screen** straight from the source at final size: light denoise, Lanczos upscale, a gentle sharpen, then the custom keyer (`_tools/greenkey.py`) and a high-quality VP9 encode with transparency.
- **Cuts the voice** with a short fade and loudness normalisation (−14 LUFS).
- **Applies the presenter grade** (`_tools/presenter-grade.json`) with `hyperframes media-treatment`: deeper blacks, whiter shirt, the pink shirt cast and green edge fringe neutralised, skin kept warm. Grades always go through this tool, never CSS filters.
- **Writes the compositions:** slides, captions, CTA and effects (grain, vignette, logo).

For a new project, also copy `hyperframes.json` and `package.json` from `videos/cuet-reel-02k/`.

### Step 5: Check and look

```bash
cd videos/<reel dir> && npx hyperframes check --json
```

```bash
npx hyperframes snapshot --at 0,3,8,12,18,22,25 --no-end
```

Fix every error. Then look at the frames for the things in the checklist below.

### Step 6: Render and compress

```bash
npx hyperframes render -o renders/raw.mp4
```

```bash
ffmpeg -i renders/raw.mp4 -c:v libx264 -preset slow -crf 20 -pix_fmt yuv420p -movflags +faststart -c:a copy renders/<reel>.mp4
```

The raw render is huge because of the film grain (around 170 MB). CRF 20 keeps it sharp at around 70 MB; CRF 23 gives about 17 MB with a little softness. `renders/` is git-ignored.

## 4. Lessons from review (already built into the template)

1. **No static opening card.** Start on the face with the hook overlaid.
2. **No abrupt ending.** Don't clip the last word; hold the face, then fade in the CTA with a whoosh and an impact.
3. **Graphic text in English**, captions in his words.
4. **Colour and clarity:** key from the original source rather than a compressed copy, scale once at final size, sharpen lightly and grade the presenter. Never stretch a soft key in the browser.
5. **Captions never on his head:**
   - In full view they sit on his chest.
   - In split view they sit above the face card.
   - They hide for about 0.4 s while the face moves between layouts.
6. **Text clear of the hair.** Keep the hero sizes as set (hook 170 px, hero overlay 190 px) and drop the zoom on any beat that has an overlay above the head.
7. **Hide data rows until he says them**, and grow the bars as he says the number. Bars use an honest 0–1000 scale.

## 5. QA checklist (every reel)

- [ ] Frame 0: face plus a readable hook, no title card
- [ ] Every slide and overlay is in English; exactly one red serif word per frame
- [ ] Layout switches every 2–4 s and each switch lands on a new idea
- [ ] No caption crosses the face, hair or mouth (check the frames just after each switch)
- [ ] No headline wraps a single word onto its own line
- [ ] Numbers on screen match what he says, and appear when he says them
- [ ] The last word is complete and the face holds before the CTA
- [ ] The CTA reads "COMMENT *MENTOR*" and holds for 3 s
- [ ] `check` shows no errors; the render matches the expected length
